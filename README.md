# Dinosaur Run

彩色像素风恐龙跑酷网页小游戏，带局外进化树与基因获取倍率。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。

## 操作

- **跳跃**：空格 / ↑ / W，或触屏点按
- **下蹲**：↓ / S，或触屏下滑
- **空中微调**（解锁气流微调后）：← → / A D

## 局外成长

- **敏捷**：缩短起跳/下蹲前摇、二段跳、空中微调
- **装甲**：护盾、无敌帧、碰撞容错、落地硬直
- **感知**：夜视、障碍预警、开局冲刺
- **基因**：提高每局 DNA 结算倍率

解锁节点会改变恐龙外观；成就可装备限定底层皮肤。进度保存在浏览器 `localStorage`。

## 构建

```bash
npm run build
npm run preview
```
